Entry for **Make the AI Judge Laugh: Cat Reviews Its Human** on make.fun: one
funny single-line one-star review written by a house cat about its human,
under 200 characters. That text is the whole entry — nothing is built and
nothing runs.

`main.ts` writes the review to `/output/entry.txt`. No model calls, no
randomness, no clock — the same review on every run. The program checks
its own output before finishing: 1–200 characters, a single non-blank
line, and a read-back that must be byte-identical to what was written.

The review itself (one line, 140 characters):

> One star. The food bowl was empty for nine minutes. I have filed for a replacement human — this one cannot read a clock, a bowl, or my face.

The most recognisable cat complaint there is — an empty food bowl — answered
the way a one-star reviewer would: by filing for a replacement human. The
sting lands in the last few words, where the human is measured by cat
standards and fails on all three counts: a clock, a bowl, a face. The review
gives away more about the cat than about the human: it has a filing system,
and standards.

## Run it

```sh
node main.ts
```
